# Installation ROADGUARD 11.14.259

Importer le dossier `ROADGUARD-11.14.259` du ZIP complet dans CodeAssist, puis compiler l’application téléphone. Aucun APK n’est inclus. Les cartes déjà téléchargées restent dans les données de l’application si la mise à jour utilise le même identifiant et une signature compatible.

Contrôler d’abord Graphite Jour et Nuit, puis la carte locale sans réseau. La carte en ligne raster ne reproduit pas encore toutes les couleurs de l’exemple vectoriel. En conduite, le point GPS doit rester près du centre ; un glissement volontaire affiche « SUIVI GPS EN PAUSE · REPRENDRE ». Le toucher, ou ⌖, reprend le suivi.

Dans « Télécharger les cartes », le bouton « France complète » lance le pack métropole et Corse (2,70 Gio, archive datée du 22/12/2024). Prévoir de la place et idéalement le Wi-Fi. La carte complète est utilisée sur la France à la place des anciens morceaux régionaux ; leurs fichiers sont supprimés automatiquement une fois France complète installée et contrôlée. Le Nord-Est régional publié reste invalide, mais la carte nationale le couvre. Si le serveur est indisponible ou si son fichier change, le téléchargement est refusé sans installer une carte partielle.

Dans cette version : la barre du bas contient Carte, Alertes, Signaler, Options ; la recherche de destination reste dans la carte et le menu. Les radars et leur installation se trouvent sur le même écran. Les quatre anciennes cartes régionales françaises sont masquées et leurs fichiers sont supprimés une fois France complète validée. Ne supprime pas manuellement les anciennes données avant l’installation nationale.

Le téléchargement de toutes les cartes PMTiles du catalogue est lancé dans un service Android avec une notification. Fermer le menu ou quitter l’écran laisse le transfert actif ; « Suspendre » dans la notification arrête le transfert et permet une reprise ultérieure. Si Android arrête le service ou le téléphone redémarre, relancer le bouton reprend les octets déjà enregistrés. Prévoir la taille de la carte plus 128 Mio libres.

Le filtre radar demande un cap GPS fiable. Si un trajet routier calculé est disponible et le GPS précis, il écarte les points derrière le véhicule ou trop éloignés du tracé ; sans trajet, il utilise la direction et la distance latérale estimées. Il annonce d’abord le radar pertinent le plus proche. Aucun de ces calculs ne garantit la chaussée exacte ou le sens publié par une source radar. Essayer sur routes parallèles et carrefours avant de se fier aux annonces.
