# Installation ROADGUARD 11.14.251

Ce ZIP contient le projet Android téléphone complet et le catalogue PMTiles intégré. Aucun APK 11.14.251 compilé n'est inclus. Le fichier APK 11.14.250 de l'archive précédente n'implémente pas les téléchargements et n'a pas été recopié dans celle-ci.

Dans CodeAssist, importe le dossier `ROADGUARD-11.14.251`, laisse Gradle télécharger sa distribution et compiler `app` en mode téléphone. Après installation : Paramètres → Cache et cartes téléchargeables → Télécharger des cartes hors connexion. Rechercher une zone, télécharger, puis toucher l'entrée installée pour l'ouvrir. Une seule archive est affichée à la fois ; plusieurs archives peuvent être stockées.

La carte téléchargée remplace le fond de carte de l'écran lorsqu'elle est sélectionnée. L'itinéraire hors réseau complet et la transition automatique à la frontière attendent encore un développement.
