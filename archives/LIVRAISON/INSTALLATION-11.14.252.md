# Installation ROADGUARD 11.14.252

Ce ZIP contient un seul projet Android téléphone complet, avec code, assets, catalogues, tests, licences et configuration Gradle. Il n'inclut aucun APK de cette version ni les 93 archives régionales volumineuses : ces dernières se téléchargent dans l'application, une à la fois.

Dans CodeAssist, importer le dossier `ROADGUARD-11.14.252`, compiler `app` en variante téléphone, puis installer l'APK produit. Ouvrir « Cache de la carte → Télécharger des cartes hors connexion ». Les cartes enregistrées sont vertes « Téléchargée », celles encore absentes rouges « Télécharger ». L'ouverture affiche ensemble toutes les cartes enregistrées ; aucune sélection exclusive n'est nécessaire. Internet couvre les zones absentes lorsqu'il est disponible.

Compiler et vérifier sur le téléphone le rendu MapLibre ainsi que France Sud-Est / Suisse en mode avion et au passage de frontière. Le routage entièrement hors ligne n'est pas encore établi par ces packs.
