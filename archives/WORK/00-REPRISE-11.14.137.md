# Reprise ROADGUARD 11.14.137

## Demande utilisateur
Les radars restent le point bloquant. L’utilisateur partage une capture RadarDroid de son écran de fournisseurs (Kostenlos DB, GPS Data Team, SCDB, etc.). Il veut que ROADGUARD puisse proposer des bases pour d’autres pays.

## État de cette livraison
- Une liste de fournisseurs est ajoutée à Alertes → Bases radar par pays.
- Lufop et SCDB sont résumés à partir de leurs pages actuelles; GPS Data Team et Kostenlos DB, cités dans la capture, sont explicitement marqués non vérifiés pour ROADGUARD.
- Lufop propose une API avec clé et quota limité; ses ZIP RadarDroid ne sont pas directement compatibles avec le CSV du catalogue ROADGUARD.
- Aucun pack radar étranger n’est activé. Il faut encore choisir/intégrer un flux et obtenir les droits nécessaires.
- Version source 11.14.137 / code 337; pas d’APK compilée ni testée sur téléphone.
- Estimation radar 83 %, global 75 %, non auditée.
- Aucun préchargement de carte. Caméra reste reportée à la dernière étape.
