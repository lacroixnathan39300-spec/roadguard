# Reprise ROADGUARD 11.14.161

Version source 11.14.161 / code 361. Le lien direct `/radardroid-lufop-XX` a été retiré car la page indique qu’il est réservé à Radardroid. La page Lufop propose aussi des archives ZIP multi-pays standard; ROADGUARD sait désormais importer l’archive, sélectionner les CSV `CH*`, préserver les catégories et retirer les doublons. L’utilisateur doit d’abord obtenir le ZIP via le centre officiel Lufop (connexion éventuellement nécessaire), puis l’importer dans l’application.

Les données suisses sont conservées, mais les chargeurs carte et alertes les ignorent. Les deux sources réseau sans clé restent MapAtlas et OpenStreetMap; l’API Lufop avec clé demeure disponible séparément. Import Xiaomi et compilation non testés.
