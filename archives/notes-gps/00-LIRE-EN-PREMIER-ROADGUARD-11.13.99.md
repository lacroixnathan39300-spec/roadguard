# ROADGUARD 11.13.99 — Interface / boutons (lot 1)

Base: 11.13.98, version 11.13.96 ×10 conservée.

## Réalisé
- Boutons génériques : surfaces tactiles minimales 56 dp, contraste du contour renforcé, effet tactile Android natif, retour haptique au clic.
- Navigation : indication d’onglet actif pour accessibilité, effet tactile, pas de reconstruction de l’écran si l’onglet est déjà actif.
- Commande « Centrer » : description accessible explicite.
- Anticipation de carte : libellé accessible clarifié pour éviter la confusion avec la caméra physique.
- Aucune modification de la fonctionnalité caméra physique.
- Cache ×10, GPS, radars et cartographie non modifiés.

- Le code de navigation conserve les boutons et fonctions existants.
