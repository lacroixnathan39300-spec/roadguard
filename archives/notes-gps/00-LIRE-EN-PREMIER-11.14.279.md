# ROADGUARD 11.14.279 — crédits miniatures

Le crédit cartographique se replie derrière un symbole ⓘ de 16 pixels CSS en bas à droite. Sa zone d'appui transparente mesure 36 × 36 pixels CSS. Un appui ouvre les crédits lisibles, un autre les replie. Leaflet conserve l'état du bouton quand les sources changent ; MapLibre utilise son contrôle compact natif. Les crédits de chaque source restent disponibles. La position suit le panneau de recherche.

Contrôle : syntaxe JavaScript des pages modifiées. Aucun nouveau contrôle Android complet ni essai Xiaomi. Compilation non réalisée dans cet environnement.

🔴 INTERVENTION OBLIGATOIRE : importer le projet dans CodeAssist, compiler et installer la mise à jour, puis essayer ⓘ sur la carte en ligne et la carte locale.
