# ROADGUARD 11.14.271 — Mon compte visible

La nouvelle page « Mon compte » est accessible depuis l'accueil, le menu de la carte et les paramètres. Elle explique la connexion gratuite sans SMS, affiche l'état de l'association et propose un bouton explicite « Créer mon compte / Se connecter ».

Le bouton ouvre le parcours d'association déjà mis en place : code affiché par l'application, connexion et déclaration du numéro sur le site dans le navigateur, puis retour automatique au compte dans ROADGUARD après confirmation. La connexion n'est donc pas entièrement contenue dans l'application. Le numéro déclaré n'est pas vérifié par SMS.

Les sources Android et le site sont réunis dans ce ZIP. La version du site est déjà publiée et aucun changement du site n'est requis pour cette page.
